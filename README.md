# Gen AI Playbook

Справочник по технологиям и практикам Gen AI с позиции системного аналитика:
что есть что, как проектировать правильно и чем проверять результат.
Статический сайт без фреймворков — HTML + CSS + JS, без сборки.

## Разделы

- **RAG** — конвейер усиленной генерации: chunking, embeddings, векторные БД, гибридный поиск, reranking
- **Агенты и оркестрация** — tool calling, MCP, паттерны multi-agent, память, маршрутизация
- **Промпты и контекст** — системный промпт как спецификация, контекстное окно, structured outputs
- **Оценка качества** — golden dataset, LLM-as-a-judge, метрики RAG и агентов, замеры «до/после»
- **Guardrails и безопасность** — галлюцинации, валидация, prompt injection, OWASP LLM Top 10
- **Наблюдаемость** — трейсинг, OpenTelemetry, онлайн-метрики качества
- **Стоимость и латентность** — юнит-экономика запроса, токены, p50/p95
- **Артефакты аналитика** — спека AI-фичи, промпты как требования, BRD/HLD/ADR, НФТ
- **Глоссарий** — термины из вакансий и документации

Состав разделов собран из анализа требований вакансий «системный / Gen AI аналитик»
(хх.ру, Хабр Карьера, LinkedIn, Indeed); частота терминов по вакансиям указана в глоссарии.

## Особенности

- Контент сверен с первоисточниками (OpenAI/Anthropic, LangChain, RAGAS, OWASP, OpenTelemetry);
  ссылки — в блоке «Источники» внизу каждой страницы.
- Две темы: тёмная и светлая, переключатель в сайдбаре (запоминается локально).
- Термины-чипы кликабельны и ведут в профильный раздел.
- Дизайн в духе инженерных брендбуков: тёмно-зелёная палитра с лаймовым акцентом,
  шрифты Unbounded / Golos Text / JetBrains Mono.
- Всё работает офлайн-структурой: относительные ссылки, субpath GitHub Pages поддерживается.

## Запуск локально

Любой статический сервер, например:

```bash
python -m http.server 8000
# http://localhost:8000
```

Или просто открыть `index.html` в браузере (навигация строится скриптом из SITEMAP в `assets/app.js`).

## Структура

```
index.html          обложка
rag.html … glossary.html   разделы справочника
template.html       шаблон новой страницы
assets/style.css    дизайн-система (две темы)
assets/app.js       навигация, поиск, темы, кликабельные термины
assets/favicon.svg
```

Новая страница: скопировать `template.html`, добавить пункт в `SITEMAP` (`assets/app.js`),
ссылку на страницу — в `index.html`.
